# Mana&Bullets

<img src="github-assets/gameplay1.gif" width="600" alt="Demonstração do gameplay com hordas de inimigos">

Um jogo de sobrevivência e ação rápida onde você enfrenta hordas infinitas, coleta experiência e evolui suas armas e magias para sobreviver o máximo que conseguir.


**Controles**
- **WASD / Setas:** Movimentação da personagem.
- **Mouse:** Mirar / Navegar nos menus.
- **Esc:** Pausar.
